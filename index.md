# CS310/5102: Algorithms — Spring 2026

Course website for **CS310 / CS5102 Algorithms** at LUMS SSE, Spring 2026.

The site is live at **[amessbee.github.io/310S26](https://amessbee.github.io/310S26)** and includes:

- Syllabus and course policies
- Weekly schedule
- Lecture notes (PDF)
- Announcements
- Staff and office hours
- Resources

## Updating the site

All content is driven by JSON files in `data/` — no HTML editing required for routine updates:

| File | Controls |
|------|----------|
| `data/announcements.json` | Pinned announcements |
| `data/staff.json` | Instructor/TA list |
| `data/schedule.json` | Week-by-week schedule |
| `data/lectures.json` | Lecture notes and slides links |

Commit and push to `main`; GitHub Pages redeploys automatically (usually within 1–2 minutes).
