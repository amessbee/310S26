\item \textit{Certificates are the formal bridge between ``I claim a solution exists'' and ``I can verify one efficiently.'' Getting this definition exactly right is essential before any NP-hardness proof.}

\begin{enumerate}
    \item Formally define the complexity class $\mathbf{NP}$ using the notion of a polynomial-time \emph{verifier}. Your definition should specify: what a certificate is, what the verifier receives, and what polynomial means in terms of the input length.

    \item For each of the following problems, either (i) give a polynomial-time certificate and verifier, or (ii) explain why no short certificate is apparent. For each, state whether the problem is in $\mathbf{NP}$ (and justify briefly).
    \begin{enumerate}[label=(\roman*)]
        \item \textsc{3-Coloring}: Given a graph $G$, does it have a proper 3-coloring?
        \item \textsc{Non-3-Coloring}: Given a graph $G$, is it true that $G$ has \emph{no} proper 3-coloring?
        \item \textsc{Subset Sum}: Given integers $a_1,\ldots,a_n$ and target $T$, does some subset sum to $T$?
        \item \textsc{Shortest Path}: Given a weighted graph $G$, vertices $s,t$, and integer $k$, is the shortest path from $s$ to $t$ at most $k$?
    \end{enumerate}

    \item The class $\mathbf{co\text{-}NP}$ consists of all problems whose \emph{complements} are in $\mathbf{NP}$. Identify which problems from part (b) are in $\mathbf{co\text{-}NP}$, and explain what a co-certificate would look like for \textsc{Non-3-Coloring}.

    \item Prove that if $\mathbf{P} = \mathbf{NP}$, then $\mathbf{NP} = \mathbf{co\text{-}NP}$. (\textit{Hint: $\mathbf{P}$ is closed under complement.})
\end{enumerate}

\item \textit{Polynomial-time reductions are the formal tool for comparing problem difficulty. Getting the direction right is the most common source of confusion.}

\begin{enumerate}
    \item State the formal definition of a polynomial-time many-one reduction $A \leq_p B$. What does it mean for the reduction to be \emph{correct}? What does $A \leq_p B$ imply about the relative difficulty of $A$ and $B$?

    \item Suppose you want to show that problem $X$ is NP-hard. Your friend claims: ``I reduced $X$ to \textsc{3-SAT} in polynomial time, so $X$ is NP-hard.'' Is your friend correct? Explain precisely what went wrong (or right) with their reasoning.

    \item We know \textsc{3-SAT} $\leq_p$ \textsc{Independent Set} and \textsc{Independent Set} $\leq_p$ \textsc{Vertex Cover}. Using these facts, prove that if \textsc{Vertex Cover} $\in \mathbf{P}$, then $\mathbf{P} = \mathbf{NP}$.

    \item True or false (with proof or counterexample): If $A \leq_p B$ and $B \leq_p A$, then $A \in \mathbf{P}$ if and only if $B \in \mathbf{P}$. Can both $A$ and $B$ be NP-complete?
\end{enumerate}

\item \textit{This problem asks you to construct a concrete NP-completeness proof from scratch for a problem that looks deceptively simple.}

Define the \textsc{Exact Cover by 3-Sets (X3C)} problem: Given a universe $U = \{u_1,\ldots,u_{3k}\}$ and a collection $\mathcal{S}$ of subsets of $U$ each of size exactly 3, does $\mathcal{S}$ contain $k$ pairwise disjoint subsets that together cover $U$?

\begin{enumerate}
    \item Show that \textsc{X3C} $\in \mathbf{NP}$ by describing a polynomial-time verifier.

    \item We will reduce from \textsc{3-SAT}. Given a 3-CNF formula $\varphi$ with variables $x_1,\ldots,x_n$ and clauses $C_1,\ldots,C_m$, construct a universe and collection of 3-element sets encoding $\varphi$ such that an exact cover exists if and only if $\varphi$ is satisfiable. Explicitly describe your variable gadgets and clause gadgets, and prove correctness (both directions of the if-and-only-if).

    \item Conclude that \textsc{X3C} is NP-complete.

    \item Give a polynomial-time algorithm for \textsc{X3C} when $k \leq 3$ (i.e., at most 9 elements in $U$). Does this contradict NP-completeness?
\end{enumerate}

\item \textit{The relationship between Independent Set, Clique, and Vertex Cover is one of the most elegant structures in NP-completeness theory.}

Recall:
\begin{itemize}
    \item \textsc{Independent Set}: Given $G=(V,E)$ and $k$, does $G$ have an independent set of size $\geq k$?
    \item \textsc{Clique}: Given $G=(V,E)$ and $k$, does $G$ have a clique of size $\geq k$?
    \item \textsc{Vertex Cover}: Given $G=(V,E)$ and $k$, does $G$ have a vertex cover of size $\leq k$?
\end{itemize}

\begin{enumerate}
    \item Prove: $S \subseteq V$ is an independent set of $G$ if and only if $S$ is a clique in the complement graph $\bar{G}$. Use this to give a polynomial-time reduction from \textsc{Independent Set} to \textsc{Clique}.

    \item Prove: $S \subseteq V$ is an independent set if and only if $V \setminus S$ is a vertex cover. Use this to give a polynomial-time reduction from \textsc{Independent Set} to \textsc{Vertex Cover}.

    \item Give the graph $G$ below. Find (i) the maximum independent set, (ii) the minimum vertex cover, and (iii) the maximum clique in $\bar G$. Verify that your answers are consistent with the relationships above.
    \[
    G: \quad \text{vertices } \{1,2,3,4,5,6\},\quad \text{edges } \{12,13,23,34,45,56,16\}.
    \]

    \item The \textsc{Dominating Set} problem asks: given $G$ and $k$, does there exist $S \subseteq V$ with $|S| \leq k$ such that every $v \notin S$ has a neighbor in $S$? Is \textsc{Dominating Set} the same as \textsc{Vertex Cover}? Prove or give a counterexample.
\end{enumerate}

\item \textit{This problem introduces circulations, which generalize flows and unify several seemingly different problems.}

A \emph{circulation} in a directed graph $G=(V,E)$ with capacities $c: E \to \mathbb{Z}_{\geq 0}$ is a function $f: E \to \mathbb{Z}_{\geq 0}$ such that:
\begin{itemize}
    \item \textbf{Capacity}: $0 \leq f(e) \leq c(e)$ for all $e$.
    \item \textbf{Conservation}: $\sum_{e \text{ into } v} f(e) = \sum_{e \text{ out of } v} f(e)$ for every $v \in V$.
\end{itemize}

\begin{enumerate}
    \item Show that any $s$-$t$ max-flow instance can be converted to a circulation problem by adding an edge from $t$ to $s$ with capacity $\infty$. What is the correspondence between maximum circulation on $e = (t,s)$ and maximum $s$-$t$ flow?

    \item \textbf{Feasibility of a circulation}: Prove that a feasible circulation exists in $G$ if and only if for every subset $S \subseteq V$,
    \[
        \sum_{e \text{ from } S \text{ to } V \setminus S} c(e) \geq 0.
    \]
    (This is trivially true when all capacities are nonnegative. What does it say for lower-bounded circulations?)

    \item \textbf{Decomposition theorem}: Prove that any feasible integer circulation can be decomposed into a set of directed cycles, each carrying a positive integer amount of flow, such that no edge's capacity is exceeded. \textit{(Hint: while the flow is nonzero, find a cycle in the support of $f$ and subtract it.)}

    \item Design a flow network to solve the following scheduling problem: a factory runs 24 hours a day. At each hour $h$ ($h = 1, \ldots, 24$), it needs at least $d_h$ workers on shift. Each worker works a consecutive 8-hour block starting at some hour. Minimize the total number of workers hired using a circulation with lower bounds.
\end{enumerate}

\item \textit{Baseball elimination is a classic application of max-flow with a surprising certificate of infeasibility.}

In a round-robin sports league with teams $\{1, 2, \ldots, n\}$, team $i$ has won $w_i$ games so far and teams $i$ and $j$ have $r_{ij}$ games remaining against each other. Team $n$ (the ``query team'') has won $w_n$ games so far and has $R_n$ total games remaining. Team $n$ is \emph{eliminated} if no matter how the remaining games are played, it cannot finish with the most wins.

\begin{enumerate}
    \item Give a \emph{trivial} condition under which team $n$ is immediately eliminated (no flow computation needed).

    \item Suppose team $n$'s maximum possible wins is $W^* = w_n + R_n$. Construct a flow network on teams $T = \{1,\ldots,n-1\}$ and game nodes $\{(i,j) : i < j,\; i,j \in T\}$ such that team $n$ is \emph{not} eliminated if and only if the max flow in your network equals $\sum_{i < j,\; i,j \in T} r_{ij}$.

    \item Apply your algorithm to the following 4-team league to determine if team 4 is eliminated:

    \medskip
    \begin{center}
    \begin{tabular}{c|c|cccc}
        Team & Wins & vs.\ 1 & vs.\ 2 & vs.\ 3 & vs.\ 4 \\
        \hline
        1 & 83 & --- & 1 & 6 & 1 \\
        2 & 80 & 1 & --- & 0 & 2 \\
        3 & 78 & 6 & 0 & --- & 0 \\
        4 & 76 & 1 & 2 & 0 & --- \\
    \end{tabular}
    \end{center}
    \medskip

    \item If the max flow is less than $\sum r_{ij}$, the min cut gives a \emph{certificate of elimination}: a subset $S \subseteq T$ such that $w_n + R_n < \frac{1}{|S|}\left(\sum_{i \in S} w_i + \sum_{i,j \in S} r_{ij}\right)$. Interpret this certificate in words: what does it mean for team $n$ to be eliminated by the group $S$?
\end{enumerate}

\item \textit{This problem probes the boundary between NP-hardness and polynomial-time solvability using flows.}

For each of the following problems, determine whether it is solvable in polynomial time (possibly via a flow reduction) or is NP-hard. In each case, prove your answer.

\begin{enumerate}
    \item \textbf{Maximum flow with minimum number of edges}: among all maximum flows in a network, find one that uses the fewest edges with strictly positive flow. (An edge is ``used'' if $f(e) > 0$.)

\begin{enumerate}

\item 
Give a formal definition of NP using polynomial-time verifiers.

\textbf{Answer:}  
A language $L$ is in NP if there exists a polynomial-time algorithm $V(x, y)$ (verifier) and a polynomial $p(n)$ such that:
\[
x \in L \iff \exists y \text{ with } |y| \le p(|x|) \text{ and } V(x,y)=1.
\]
Here, $y$ is called a certificate. The verifier runs in time polynomial in $|x|$.

\vspace{0.5em}

\item 
Explain why every problem in P is also in NP.

\textbf{Answer:}  
If a problem is in P, we can solve it in polynomial time without any certificate. The verifier can ignore $y$ and simply compute the answer directly in polynomial time.

\vspace{0.5em}

\item 
If $A \leq_p B$ and $B \in P$, what can you conclude about $A$?

\textbf{Answer:}  
$A \in P$. We can reduce $A$ to $B$ in polynomial time and then solve $B$ in polynomial time, giving a polynomial-time algorithm for $A$.

\vspace{0.5em}

\item 
If $A \leq_p B$ and $A$ is NP-complete, what can you conclude about $B$?

\textbf{Answer:}  
$B$ is NP-hard. If additionally $B \in NP$, then $B$ is NP-complete.

\vspace{0.5em}

\item 
Define NP-hard and NP-complete.

\textbf{Answer:}  
NP-hard: A problem $B$ is NP-hard if for every $A \in NP$, $A \leq_p B$.  
NP-complete: A problem is NP-complete if it is both NP-hard and in NP.

\vspace{0.5em}

\item 
What happens if SAT is in P?

\textbf{Answer:}  
Then $P = NP$. All NP-complete problems become solvable in polynomial time, and many optimization problems become efficiently solvable via decision versions.

\vspace{0.5em}

\item 
Describe the key idea of the 3SAT $\rightarrow$ CLIQUE reduction.

\textbf{Answer:}  
Create one vertex per literal per clause. Connect vertices from different clauses if they are not contradictory. A $k$-clique corresponds to selecting one consistent literal per clause.

\vspace{0.5em}

\item 
Is EXACT-CLIQUE NP-complete?

\textbf{Answer:}  
Yes. It is in NP (certificate = set of vertices). It is NP-hard since CLIQUE reduces to it by asking if there is a clique of size at least $k$, which can be converted to exactly $k$ by minor adjustments or checking all sizes.

\vspace{0.5em}

\item 
Is $n^{\log n}$ polynomial?

\textbf{Answer:}  
No. Polynomial time is $n^c$ for constant $c$. Since $\log n$ is not constant, $n^{\log n}$ is superpolynomial.

\vspace{0.5em}

\item 
Does squaring weights preserve shortest paths?

\textbf{Answer:}  
Not necessarily. Squaring is not a linear transformation and can change relative differences. A path with smaller edges may become worse after squaring.

\vspace{0.5em}

\item 
Explain unary vs binary encoding.

\textbf{Answer:}  
Binary encoding represents a number $n$ in $\log n$ bits. Unary uses $n$ bits. Thus unary encoding increases input size significantly and can make some problems easier.

\vspace{0.5em}

\item 
Does unary encoding affect NP-completeness?

\textbf{Answer:}  
Yes. Some problems (e.g., Knapsack) become solvable in polynomial time with unary encoding because the input size becomes large relative to numeric values.

\vspace{0.5em}

\item 
If a certificate needs sorting before verification, is the problem in NP?

\textbf{Answer:}  
Yes. Sorting takes $O(n \log n)$, which is polynomial, so the verifier still runs in polynomial time.

\vspace{0.5em}

\item 
Why does $B \leq_p A$ not imply $A$ is NP-hard?

\textbf{Answer:}  
Because this only shows $A$ is at least as easy as $B$. To prove NP-hardness, all NP problems must reduce to $A$, not just one.

\vspace{0.5em}

\item 
Does repeating each bit 100 times change NP-completeness?

\textbf{Answer:}  
No. The transformation only increases input size by a constant factor, which preserves polynomial-time reductions and NP-completeness.

\vspace{0.5em}

\item 
What is the max-flow min-cut theorem?

\textbf{Answer:}  
The maximum value of an $s$-$t$ flow equals the minimum capacity of an $s$-$t$ cut.

\vspace{0.5em}

\item 
Why can Ford--Fulkerson fail with irrational capacities?

\textbf{Answer:}  
Because augmenting paths may add arbitrarily small flow increments, leading to non-termination.

\vspace{0.5em}

\item 
What happens when all capacities are 1?

\textbf{Answer:}  
The problem reduces to finding the maximum number of edge-disjoint paths.

\vspace{0.5em}

\item 
How do you find edge-disjoint paths using flow?

\textbf{Answer:}  
Set all edge capacities to 1 and compute max-flow. Each unit of flow corresponds to one edge-disjoint path.

\vspace{0.5em}

\item 
How do you enforce vertex capacity in flow?

\textbf{Answer:}  
Split each vertex into $v_{in}$ and $v_{out}$ with an edge between them having the desired capacity.

\vspace{0.5em}

\item 
How do you ensure flow passes through a node in set $S$?

\textbf{Answer:}  
One method: remove all paths that bypass $S$ by splitting nodes and restricting edges so that any $s$-$t$ path must pass through nodes in $S$ (e.g., connect through a super-node representing $S$).

\vspace{0.5em}

\item 
Is the following problem in NP?  
“Assign directions to edges so that flow $\ge k$ exists.”

\textbf{Answer:}  
Yes. Certificate: direction assignment + flow. Verification: check flow feasibility in polynomial time.

\vspace{0.5em}

\item 
Give an argument that the above problem may be NP-hard.

\textbf{Answer:}  
It resembles choosing orientations to satisfy constraints, similar to reductions from SAT or cut problems, suggesting NP-hardness though a full reduction is needed.

\end{enumerate}
